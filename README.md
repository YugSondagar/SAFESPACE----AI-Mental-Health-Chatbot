🧠 SafeSpace – AI Mental Health Assistant

An empathetic AI-powered chatbot designed to provide 24/7 mental wellness support, detect emotional distress, and take real-time action in crisis situations.

📌 Overview

SafeSpace is built to address the growing need for accessible mental health support. It uses NLP and real-time analysis to understand user emotions and provide supportive, human-like responses.

In critical situations, the system goes beyond conversation by triggering emergency assistance, making it a proactive mental health companion.

✨ Key Features
💬 Empathetic AI Chatbot – Provides supportive, human-like conversations
🧠 Sentiment & Risk Detection – Identifies emotional distress, suicidal thoughts, and self-harm signals
🚨 Crisis Response System – Detects high-risk situations in real time
📞 Emergency Call Integration – Automatically contacts helplines or trusted individuals using Twilio
⏱️ 24/7 Availability – Always accessible mental wellness support
